Тот же кабинет директора: светофор, восемь модулей и план на 30 дней. В правом нижнем углу — когда выходит пост (13:30) и Reels (18:00).


## Автомат дня

Каждый день берёт дату, находит её в плане (30 дней с 31.10.2026) и отдаёт готовый пакет. Если даты нет в плане — рубрика по дню недели: Пн Заметка, Вт Спор, Ср Ностальгия, Чт Событие, Пт Гость, Сб Закулисье, Вс Тишина.

```bash
npm run post:day                                  # пакет на сегодня
npm run post:day -- --date 2026-11-27            # пакет на дату
npm run post:plan                                 # таблица 30 дней
npm run post:log -- --date 2026-11-26 --replies 4 --reach 1800 --likes 42 --rubric "События"
npm run post:week                                 # сводка за 7 дней и замена слабой рубрики
```

В кабинете то же самое открывается во вкладке «Автомат дня»: пост, три кадра (макро-эмоция → предметка → движение), афиша фоном и блоками, чек-лист публикации, учёт и сводка недели. План таблицей — `docs/plan-30.md`. Учёт для сводки — `src/data/contentLog.json`.
