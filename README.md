# RESTPRIME — календарь KEDR

Кабинет директора: календарь на 30 дней, крупные тексты, очереди Instagram и Telegram, подбор формата и стол разработчика.

Живые публикации в Instagram и Telegram из браузера не отправляются: текст копируется, сервис открывается, очередь и статус остаются в кабинете. Вход администратора проверяется на этом устройстве, пароль в репозиторий не записан.

```bash
npm install
npm run dev
```

Кабинет: http://127.0.0.1:5173
