# RESTPRIME — кабинет KEDR

Операционный экран директора ресторана [KEDR](https://kedr-res.ru/): светофор дня, план на 30 дней, посты, Reels, темы, разбор ролика, файлы, учебные охваты и комната команды.

Стек: Vite, React 18, Tailwind, Framer Motion, Lucide. Роутинг — состояние экрана, без React Router. Живые Meta, Telegram, Supabase и OpenAI сюда ещё не подключены: цифры Instagram и разбор ролика собраны на клиенте.

```bash
npm install
npm run dev
```

Кабинет открывается на http://127.0.0.1:5173
