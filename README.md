# RESTPRIME & KEDR

AI-экосистема ресторанного маркетинга. Флагманский кейс — ресторан [«Кедр»](https://kedr-res.ru/), д. Зайцево, ул. Сосновая, д. 3.

Два приложения в одном репозитории, чтобы витрина и кабинет не спорили из-за стека.

- `apps/web-journey` — публичный киношный сайт. Vite 6, многостраничный, без React.
- `apps/app-dashboard` — кабинет RESTPRIME. Матрица на 30 дней, радар, файлы, Instagram-срез, комната команды.

## Запуск

```bash
npm install --prefix apps/web-journey
npm install --prefix apps/app-dashboard
npm run dev:journey
npm run dev:dashboard
```

Витрина: http://127.0.0.1:5173  
Кабинет: http://127.0.0.1:5174

Сборка обоих: `npm run build`.

## Что уже работает локально

Витрина: свой цикл скролла, пыль света на canvas, лента интерьеров, бронь в браузере, политика и страница безопасности. Оплата на сайте не принимается.

Кабинет по умолчанию открывает KEDR. Светофор показывает сегодняшний пост, Reels и Stories. Четыре режима месяца и четыре модуля переключаются кнопками. Карточка дня в покое держит только суть; действия поднимаются вместе с ней. Файлы Word, Excel и PDF разбираются в браузере. Сообщения Telegram складываются в локальную очередь и никуда не отправляются. Цифры Instagram — учебный срез, не выгрузка Meta.

Новый ресторан добавляется кнопкой в шапке: меняются имя, тон и подписи. Календарные темы при этом остаются лесной гастрономией кейса и переписываются под новое имя.
